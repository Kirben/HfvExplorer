HFVExplorer x64: image-only experimental port
2026-11-15

This is a local, unofficial port of ObsoleteMadness/HfvExplorer at
55a0eb7e2df20fc5d83262aabedc78712be2b9d3. Original HFVExplorer authorship,
copyright notices and GPL licensing are preserved. It is not an official
release by Lauri Pesonen or Anygraaf.

Run
Open the HFVExplorer-x64-images folder and run HFVExplorer.exe. Keep it in a writable location.
No driver, administrator privileges or MFC runtime installation is required
to run the statically linked executable. Use File > Open volume for HFV/DSK
images. Normal Windows folders remain visible for file transfers.
Preferences are saved beside the executable in HFVExplorer-x64.ini.
This port does not automatically register file associations.

Scope
- Classic HFS disk images; this does not add HFS+ support.
- Physical Macintosh floppies, CDs, removable disks, eject/reload and CD
  burning are disabled. No cdenable.sys, VxD or VWIN32 code is built.
- Windows manages display scaling because the legacy layout uses fixed pixels.
  This improves readability on high-DPI displays; bitmap icons may be soft.
- Old emulator integrations and WinHelp are not validated by this port.
- Large-file offsets have not been modernized. Use images smaller than 2 GiB;
  an x64 executable does not itself remove the historical offset limits.

Build
Requires Visual Studio 2026 C++ tools (v145), Windows SDK and the MFC x86/x64
component Microsoft.VisualStudio.Component.VC.ATLMFC.
From PowerShell in this checkout:
  .\build-x64.ps1
  .\build-x64.ps1 -Test
Or open src/HFVExplorer-x64.vcxproj and select Release | x64.
The application is written to bin/x64/HFVExplorer.exe.
This initial Release configuration deliberately uses unoptimized compilation
to simplify debugging of the old code. Existing non-pointer conversion and
deprecated API warnings remain; a successful build is not an exhaustive audit.

Changes
- Added a current MSBuild x64/MFC project and driver-free ImageOnly backend.
- Replaced pointer/handle DWORD containers and item data with pointer-width
  storage. Corrected pointer differences, sort payloads and message signatures.
- Updated incompatible CRT declarations, const usage, reserved identifiers,
  old constructor calls, wide-character buffers and ctime argument types.
- Fixed List/Details command IDs colliding with current MFC resources.
- Disabled physical-media UI commands and startup discovery.
- Isolated preferences and retained manual control over file associations.
- Disabled the incorrect DPI-aware manifest declaration.

Validation
- Built and linked natively as PE32+ AMD64 with MSVC 14.51.36231/MFC.
- Image integration test creates a disposable 16 MiB HFS image, mounts it,
  creates a directory/file, writes patterned data and resource forks, renames,
  flushes/unmounts, reopens read-only, verifies both forks byte-for-byte and
  Finder type/creator metadata, enumerates, deletes and verifies persistence.
- The same core HFS sources are compiled into the test and the GUI.
- UI smoke test opened the populated image and browsed its folder/file.
- GUI import/export, complex real-world volumes, emulator launching and
  cross-machine compatibility have not been exhaustively tested.
