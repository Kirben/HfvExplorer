Floppy menu and General options update
=====================================
Target platforms: Windows 7 SP1 + KB2533623 (or superseding update), Windows
8/8.1, 10 and 11 x64. See WINDOWS-COMPATIBILITY.txt for validation status.

File > Format new volume... lists removable drives in its destination list.
Selecting <Format floppy A:> fixes the size to 1440 kB. Choose a volume name
and OK to confirm erasure, then show progress with that drive and name.
The erase confirmation is still required; no write occurs just by selecting
the drive. USB/removable devices that do not match 1.44 MB floppy geometry
are rejected by the writer. Image-file creation remains available separately
in the same destination field; initializing an existing empty image cannot
redirect the operation to a physical drive.

File > Read volume from floppy... saves a raw sector image using the native
read-only backend. Supported sector-formatted geometries are 720 KB, 1.44 MB
and 2.88 MB. The disk need not contain HFS. Choose a destination on another
drive. A cancellable progress dialog reports overall bytes. Media-change or
read errors discard the partial temporary image; existing destinations require
an overwrite choice. Missing sectors are never synthesized.

File > Write volume to floppy... uses the original path-and-drive dialog.
It writes a validated 1.44 MB classic HFS image. Use Format new volume to create
an empty HFS floppy.
The existing erase confirmation, geometry checks, locking, media-change checks
and complete readback verification remain in use. This overwrites the disk.
720 KB and 2.88 MB writing are not supported. Macintosh 400/800 KB GCR disks
cannot be read by an ordinary PC/USB floppy drive.

Options > General > Check for Mac floppies at startup is enabled and its saved
setting is honored. Enable it if a previous build saved it as off. A missing
disk/slow drive can delay startup scanning; work runs through the storage worker.
Physical hard-disk probing remains disabled. Eject/reload use native Windows
requests on eligible selected physical drives; see MEDIA-CONTROL.txt.

The Windows 95/98 CD patch checkbox and its settings code have been removed.
Native Windows CD access requires no such patch or custom driver.

Validation: Release/Test builds and simulated floppy read/write, storage wait,
copy, CD imaging/burning, Find files and new floppy-menu/General tests.
No physical drives were accessed and no computer control was used.
