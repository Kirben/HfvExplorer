Ordinary file copying to physical HFS floppies
============================================
Use normal file/folder copying onto an existing 1.44 MB classic HFS floppy.
The worker now copies directly, following the original filesystem path. It
uses a 1,000-sector cache and merges adjacent writes in a 64 KiB buffer.
There is no full-disk snapshot, temporary working image, original-disk comparison
or separate readback pass for ordinary copies. Copy progress is followed by
Flushing floppy. Formatting/full-image writing still uses full readback.

Windows imports use the selected conversion mode; HFS copies preserve both
forks and folder structure. Existing unrelated files are retained. Browsing
stays read-only; writable access is scoped to the serialized copy worker.
The worker checks HFS geometry/media identity, closes the browsing handle,
locks/dismounts the destination and uses unbuffered write-through writes.
Media-generation checks remain; a swapped disk cannot receive buffered writes.
Pending writes are flushed at completion. Unsupported explicit flush requests
are accepted for this write-through path; other flush failures are errors.
Completion confirms accepted writes, not a separate readback comparison.

Direct copying can leave partial files or filesystem changes after insufficient
space, cancellation or an I/O failure, as with the original direct-write path.
Cross-volume Move currently retains source files; same-volume moves use HFS
rename/move behavior. Keep the disk inserted until copying and flushing finish.
Normal read-only browsing does not enable arbitrary filesystem editing.
720 KB and 2.88 MB physical media remain browse/export-only.

Tests: direct write buffering, read-your-writes cache, worker-thread-only write
permission, no full-disk read/write cycles, HFS/Windows sources and both forks,
existing-reader reopening, write protection, lock/read/short-write/flush errors,
media changes before flushing, full-disk errors, source retention and responsive
single-dialog completion. All drives simulated; no computer control used.
