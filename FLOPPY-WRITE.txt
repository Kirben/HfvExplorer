Native HFS floppy formatting and image writing
=============================================
Use the original File-menu dialogs:
- Format new volume: enter a volume name and select <Format floppy A:> in
  the destination list. The supported physical target is 1440 kB (1.44 MB).
- Write volume to floppy: select a floppy drive and an existing raw 1.44 MB
  HFS image. The compact original dialog has a path, browse button and drive.
- Read volume from floppy uses that same original layout to save an image.

Formatting/writing requires an explicit erase confirmation. The native worker
locks the drive, writes the complete image and reads all sectors back. A single
progress bar reports Writing and Verifying. The main window is restored when
the operation completes. An error reports the failing stage and offset; a
diagnostic log is saved on a fixed temporary volume when available.

If a USB drive does not support an explicit flush request, a complete matching
readback using unbuffered write-through access is accepted as success. Other
flush errors remain failures. Geometry, media-change and readback checks remain.
An error after writing begins can leave an incomplete disk.

The replacement setup dialog and its low-level-format checkbox were removed.
The original File dialogs create the HFS filesystem in existing sectors; they
do not request IOCTL_DISK_FORMAT_TRACKS. Use an already sector-formatted 1.44 MB
disk, such as a disk that completes a Windows PC format successfully.

Ordinary file/folder copies to an existing Mac floppy use the direct buffered copy path described in FLOPPY-FILE-COPY.txt.
Tests use simulated devices. No physical disk was accessed for this update.
