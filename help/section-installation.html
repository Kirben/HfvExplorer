Installation

  1. Extract all of the files to the directory of your choice. HFVExplorer initially shows all HFV, DSK and HFx files from the directory of the executable, so it is convenient to place them into a directory where you have your HFV and DSK files.

    2.  
  2. If you are running Windows 95/98: move the file Cdenable.vxd to "\Windows\System" directory. This file is needed to access Macintosh formatted CD's under Windows.

    3.  
  3. If you are running Windows NT 4/5: move the file Cdenable.sys to "\Winnt\System32\Drivers" directory. This file is needed to access Macintosh formatted CD's under NT. After moving the driver, the program must be run once with system administrator rights. Later normal user rights suffice.

    4.  
  4. Start HFVExplorer and go to the options dialog (View menu). Check all of the property pages to suit your needs.
