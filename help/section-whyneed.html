Why is this program needed?


Windows 9x and Windows NT do not ship with out-of-the-box support for reading Macintosh Hierarchical File System (HFS) formatted media, and some third party solution is therefore needed.

There are many (over a dozen or so) other Win32 utilities that implement more or less the same functionality than HFVExplorer. Some of them are listed in the alternative solutions section.
